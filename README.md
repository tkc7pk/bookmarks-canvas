# Bookmarks Canvas

A customizable launcher/bookmark website with interactive canvas interface.

## Features
- Drag & drop bookmark positioning on an infinite canvas
- Sticky notes with custom colors and fonts
- Workspace tabs for multiple independent canvases
- Dual authentication (Replit Auth + local users)
- Category management with colored frames
- Mobile-friendly with touch support
- Multilingual support

## Tech Stack
- **Frontend**: React 18, TypeScript, Tailwind CSS, shadcn/ui
- **Backend**: Express.js, TypeScript
- **Database**: PostgreSQL with Drizzle ORM
- **Auth**: Replit Auth + local authentication
