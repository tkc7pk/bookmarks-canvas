データベース設計書

📋 システム概要

ユーザーがブックマークを自由に配置できるインタラクティブなキャンバスアプリケーションです。カテゴリーによる整理、ワークスペースタブ、付箋機能を提供し、デスクトップとモバイルの両方で快適に利用できます。

🔐 認証システム

デュアル認証対応： Replit認証（OAuth）とローカルユーザー認証の両方をサポート

  • Replit認証： usersテーブル（OpenID Connect）
  • ローカル認証： localUsersテーブル（username/password）
  • セッション管理： PostgreSQLベース（sessionsテーブル）

🗄️ データベーステーブル一覧

主キー (Primary Key)
外部キー (Foreign Key)
必須フィールド (Required)

👤 users (Replitユーザー)

  • id: varchar (PK) - Replit User ID
  • email: varchar - メールアドレス
  • firstName: varchar - 名前
  • lastName: varchar - 姓
  • profileImageUrl: varchar - プロフィール画像URL
  • createdAt: timestamp - 作成日時
  • updatedAt: timestamp - 更新日時

🔑 local_users (ローカルユーザー)

  • id: serial (PK) - 自動増分ID
  • username: varchar(50) - ユーザー名（一意）
  • password: varchar(255) - ハッシュ化パスワード
  • displayName: varchar(100) - 表示名
  • createdAt: timestamp - 作成日時
  • updatedAt: timestamp - 更新日時

🗂️ workspace_tabs (ワークスペースタブ)

  • id: serial (PK) - タブID
  • userId: varchar (FK) → users.id
  • name: varchar - タブ名
  • isActive: boolean - アクティブ状態
  • order: integer - 表示順序
  • createdAt: timestamp - 作成日時
  • updatedAt: timestamp - 更新日時

📁 categories (カテゴリー)

  • id: serial (PK) - カテゴリーID
  • userId: varchar (FK) → users.id
  • tabId: integer (FK) → workspace_tabs.id
  • name: text - カテゴリー名
  • color: text - 枠線色 (default: #3b82f6)
  • backgroundStyle: text - 背景スタイル (border/fill)
  • x: real - X座標 (default: 0)
  • y: real - Y座標 (default: 0)
  • width: real - 幅 (default: 300)
  • height: real - 高さ (default: 200)
  • createdAt: timestamp - 作成日時

🔖 bookmarks (ブックマーク)

  • id: serial (PK) - ブックマークID
  • userId: varchar (FK) → users.id
  • tabId: integer (FK) → workspace_tabs.id
  • categoryId: integer (FK) → categories.id
  • title: text - ブックマークタイトル
  • url: text - 対象URL
  • icon: text - アイコン (emoji/base64/text)
  • iconType: text - アイコン種別 (emoji/image/text)
  • x: real - X座標 (default: 0)
  • y: real - Y座標 (default: 0)
  • isPlaced: integer - 配置状態 (0=未配置, 1=配置済み)

📝 notes (付箋)

  • id: serial (PK) - 付箋ID
  • userId: varchar (FK) → users.id
  • tabId: integer (FK) → workspace_tabs.id
  • content: text - 付箋の内容
  • x: real - X座標 (default: 100)
  • y: real - Y座標 (default: 100)
  • width: real - 幅 (default: 200)
  • height: real - 高さ (default: 150)
  • backgroundColor: text - 背景色 (default: #fef3c7)
  • textColor: text - 文字色 (default: #1f2937)
  • fontSize: integer - フォントサイズ (default: 14)
  • createdAt: timestamp - 作成日時
  • updatedAt: timestamp - 更新日時

🗄️ sessions (セッション管理)

  • sid: varchar (PK) - セッションID
  • sess: jsonb - セッションデータ
  • expire: timestamp - 有効期限
⚠️ Replit認証に必須のテーブル - 削除禁止

📊 リレーション詳細

🔐 認証関連

  • users ↔ sessions： Replit認証のセッション管理
  • local_users： 独立したローカル認証システム

👤 ユーザーデータ

  • users → workspace_tabs： 1対多（1ユーザーは複数のタブを持つ）
  • users → categories： 1対多（1ユーザーは複数のカテゴリーを持つ）
  • users → bookmarks： 1対多（1ユーザーは複数のブックマークを持つ）
  • users → notes： 1対多（1ユーザーは複数の付箋を持つ）

🗂️ ワークスペース管理

  • workspace_tabs → categories： 1対多（カスケード削除）
  • workspace_tabs → bookmarks： 1対多（カスケード削除）
  • workspace_tabs → notes： 1対多（カスケード削除）

📁 カテゴリー管理

  • categories → bookmarks： 1対多（ブックマークはカテゴリーに属することができる）

🔧 技術仕様

💾 データベース技術スタック

  • データベース： PostgreSQL (Neon Database - サーバーレス)
  • ORM： Drizzle ORM (TypeScript対応)
  • マイグレーション： Drizzle Kit
  • バリデーション： Zod Schema
  • セッション： connect-pg-simple (PostgreSQL)

🛡️ セキュリティ機能

  • 認証： Replit Auth (OpenID Connect) + ローカル認証
  • データ分離： 全テーブルでユーザーID基準の完全分離
  • セッション管理： PostgreSQL永続化セッション
  • 入力検証： Zodスキーマによるリアルタイム検証

⚡ パフォーマンス最適化

  • インデックス： sessions.expire フィールドにインデックス設定
  • カスケード削除： タブ削除時の関連データ自動削除
  • 楽観的更新： フロントエンドでの即座なUI反映
  • リアルタイム同期： TanStack Query による効率的なキャッシュ管理

📈 運用考慮事項

  • スケーラビリティ： ユーザー分離設計により水平スケーリング対応
  • データ整合性： 外部キー制約と必須フィールド制約
  • バックアップ： Neon Databaseの自動バックアップ機能
  • 監視： API レスポンスタイムとデータベース接続監視
  • メンテナンス： Drizzle Kitによる安全なスキーマ更新
